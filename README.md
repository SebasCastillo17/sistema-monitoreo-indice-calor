# sistema-monitoreo-indice-calor

## Como usar

Primero se debe de crear un enviroment en python con 

``` python
python -m venv venv
```

Posteriormente se deben de instalar las bibliotecas con ```pip install -r requirements.txt```

## Como ejecutar el programa

Para ejecutar el programa se debe de usar 

```python
python -m src.main
```
